# User Stories

## Core / Business User Stories

### US-01 — User Registration
**User Story:**  
As a new user, I want to create an account so that I can securely manage my personal finances.

---

### US-02 — User Login
**User Story:**  
As a registered user, I want to log in to my account so that I can securely access my personal financial data.

---

### US-03 — Add Transaction
**User Story:**  
As a user, I want to add income and expense transactions so that I can keep track of my financial activity.

---

### US-04 — Manage Transactions
**User Story:**  
As a user, I want to edit and delete my transactions so that I can keep my financial records accurate and up to date.

---

### US-05 — Transaction Categories
**User Story:**  
As a user, I want to assign categories to my transactions so that I can understand how my income and expenses are distributed.

---

### US-06 — Custom Categories
**User Story:**  
As a user, I want to create my own income and expense categories so that I can organize transactions according to my personal needs.

---

### US-07 — Receipt Scanning
**User Story:**  
As a user, I want to upload a receipt image and have its transaction information automatically recognized so that I do not have to enter transaction details manually.

---

### US-08 — Budget Management
**User Story:**  
As a user, I want to create and manage monthly spending limits for expense categories so that I can control my spending.

---

### US-09 — Financial Goals
**User Story:**  
As a user, I want to create financial goals and record contributions toward them so that I can manage my savings plans.

---

### US-10 — Financial Overview
**User Story:**  
As a user, I want to see an overview of my income, expenses, budgets, and financial goals so that I can understand my current financial situation.

---

## Supporting / Secondary User Stories

### US-11 — View Transaction History
**User Story:**  
As a user, I want to view my transaction history so that I can review my previous financial activity.

---

### US-12 — Filter Transactions by Date
**User Story:**  
As a user, I want to filter transactions by a date range so that I can review my finances for a specific period.

---

### US-13 — Filter Transactions by Category
**User Story:**  
As a user, I want to filter transactions by category so that I can analyze specific types of income or expenses.

---

### US-14 — Transaction Description
**User Story:**  
As a user, I want to add an optional description to a transaction so that I can provide additional context about it.

---

### US-15 — Default Categories
**User Story:**  
As a user, I want to use predefined income and expense categories so that I can categorize transactions without creating categories manually.

---

### US-16 — Manage Custom Categories
**User Story:**  
As a user, I want to edit and delete my custom categories so that I can keep my category structure relevant to my needs.

---

### US-17 — View Monthly Budgets
**User Story:**  
As a user, I want to view all budgets for a selected month so that I can see my planned spending limits.

---

### US-18 — View Budget Progress
**User Story:**  
As a user, I want to see how much of each category budget has been used and how much remains so that I can monitor my spending.

---

### US-19 — View Income and Expense Totals
**User Story:**  
As a user, I want to see my total income and expenses for a selected period so that I can quickly evaluate my financial activity.

---

### US-20 — View Spending by Category
**User Story:**  
As a user, I want to see how much I have spent in each category so that I can identify where most of my money is going.

---

### US-21 — View Financial Goal Progress
**User Story:**  
As a user, I want to see the current progress of each financial goal so that I know how close I am to reaching its target amount.

---

### US-22 — Manage Financial Goals
**User Story:**  
As a user, I want to edit and delete my financial goals so that I can keep my savings plans accurate and relevant.

---

### US-23 — View Recent Transactions
**User Story:**  
As a user, I want to see my most recent transactions so that I can quickly review my latest financial activity.

---

### US-24 — Review Recognized Receipt Data
**User Story:**  
As a user, I want to review the merchant, date, and total amount recognized from a receipt so that I can verify the extracted information before creating or updating a transaction.

---

### US-25 — Receipt Processing Status
**User Story:**  
As a user, I want to see the processing status of an uploaded receipt so that I know whether its information was recognized successfully.
